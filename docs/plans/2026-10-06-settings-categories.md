# 설정 화면 분류

## 목표와 범위

상단과 사이드바의 설정 메뉴에서 프록시·모델, 일반·색상, MCP 게이트웨이를
전환한다. 기존 모델 계정·매핑과 MCP 등록·권한 편집기를 재사용한다. 일반 설정은
기존 Bright/Dark 테마와 사이드바 표시를 제어한다.

## 구현

- 기존 모델 화면 경로를 설정으로 마이그레이션하고 마지막 설정 분류를 저장한다.
- 세 설정 패널과 작업 화면은 마운트를 유지하여 터미널과 미저장 입력을 보존한다.
- MCP는 공간을 열지 않아도 관리할 수 있다. 작업 화면과 설정 화면의 등록 목록과
  저장된 권한을 공유하며, 오래된 초기 조회가 새 변경을 덮어쓰지 않게 한다.
- 기존 탭·패널·테마 컴포넌트와 디자인 토큰을 사용한다. 각 내용 영역이 스크롤을
  소유하고 탭은 키보드 화살표/Home/End로 이동한다.

## 검토와 수용 기준

설정 화면으로 이동할 때 native browser view를 숨기는 기존 visible 계약을 유지한다.
설정 저장은 기존 저장소를 사용하고 사용자 글로벌 CLI 설정은 변경하지 않는다.
서로 다른 화면에서 같은 커넥터를 편집하면 저장된 정책 변경만 초안을 갱신한다.

- 이전 모델 화면 상태가 설정의 프록시·모델로 복원된다.
- 세 분류를 실제 Electron 창에서 열고 테마·사이드바·MCP 권한 저장을 확인한다.
- 설정 왕복 후 PTY 세션과 입력 초안이 남는다.
- 재시작 후 마지막 분류와 일반 설정, MCP 등록·권한이 유지된다.
- 타입·린트·관련 단위/데스크톱 회귀 검사, Bright/Dark native 캡처를 확인한다.

순차 문서 검토: 범위와 UI 흐름이 기존 저장소·프로세스 수명 계약에 맞으며,
새로운 백엔드 설정 저장소나 별도 테마 체계는 필요하지 않다.
