# 설정 화면 분류

## 목표와 범위

상단과 사이드바의 설정 메뉴에서 프록시·모델, 일반·색상, MCP 게이트웨이를
전환한다. 기존 모델 계정·매핑과 MCP 등록·권한 편집기를 재사용한다. 일반 설정은
기존 Bright/Dark 테마와 사이드바 표시를 제어한다.

## 구현

- 기존 모델 화면 경로를 설정으로 마이그레이션하고 마지막 설정 분류를 저장한다.
- 세 설정 패널과 작업 화면은 마운트를 유지하여 터미널과 미저장 입력을 보존한다.
- MCP는 공간을 열지 않아도 관리할 수 있다. 작업 화면과 설정 화면의 등록 목록과
  저장된 권한을 공유하며, 오래된 초기 조회가 새 변경을 덮어쓰지 않게 한다.
- 기존 탭·패널·테마 컴포넌트와 디자인 토큰을 사용한다. 각 내용 영역이 스크롤을
  소유하고 탭은 키보드 화살표/Home/End로 이동한다.

## 검토와 수용 기준

설정 화면으로 이동할 때 native browser view를 숨기는 기존 visible 계약을 유지한다.
설정 저장은 기존 저장소를 사용하고 사용자 글로벌 CLI 설정은 변경하지 않는다.
서로 다른 화면에서 같은 커넥터를 편집하면 저장된 정책 변경만 초안을 갱신한다.

- 이전 모델 화면 상태가 설정의 프록시·모델로 복원된다.
- 세 분류를 실제 Electron 창에서 열고 테마·사이드바·MCP 권한 저장을 확인한다.
- 설정 왕복 후 PTY 세션과 입력 초안이 남는다.
- 재시작 후 마지막 분류와 일반 설정, MCP 등록·권한이 유지된다.
- 타입·린트·관련 단위/데스크톱 회귀 검사, Bright/Dark native 캡처를 확인한다.

순차 문서 검토: 범위와 UI 흐름이 기존 저장소·프로세스 수명 계약에 맞으며,
새로운 백엔드 설정 저장소나 별도 테마 체계는 필요하지 않다.

## 후속 요구: 웹 커넥터와 MCP 분리

작업 화면의 커넥터는 웹 앱 주소·격리된 로그인·웹 화면 열기를 담당한다.
설정의 MCP 게이트웨이는 Context7, Memory, 사용자 지정 HTTP 서버와 도구 권한만
관리한다. 각 등록 폼과 목록을 분리하고 터미널에는 MCP 서버만 선택하도록 표시한다.

기존 혼합 연결은 시작 시 웹 연결과 MCP 서버의 독립 레코드로 분리한다. 웹 연결의
ID는 그대로 두어 로그인 파티션과 열린 탭을 유지한다. MCP 주소·토큰·권한은 별도
레코드로 옮기고 Context7/Memory ID와 기억 파일은 유지한다. 마이그레이션은 원자적으로
저장하고 반복 실행 시 중복을 만들지 않는다. 저장소는 공유하되 웹 레코드의 MCP 호출과
MCP 레코드의 웹 열기를 메인 프로세스에서도 거부한다.

## 확정된 후속 요구: 서비스 도구 커넥터

사용자 선택에 따라 기존 웹 연결은 `웹 앱`으로 옮긴다. 설정에 `커넥터` 분류를 추가하고
Slack과 Atlassian 공식 MCP의 OAuth 인증, 연결 상태, 도구 확인과 권한 선택을 제공한다.
MCP 게이트웨이는 서비스 커넥터와 사용자 지정 MCP를 CLI에 전달하는 공통 기반이다.

Slack은 등록된 앱의 Client ID/Secret을 앱에서 입력한다. Atlassian은 공식 서버의 동적
클라이언트 등록을 사용한다. MCP SDK OAuth, PKCE, 일회용 state, 고정 loopback callback을
사용한다. 토큰·등록 정보·issuer·만료 시각은 OS 암호화 저장소에만 저장하며 렌더러에
반환하지 않는다. 공식 origin만 인증 요청에 허용하고 리디렉션으로 토큰을 전달하지 않는다.

로그인 시작 IPC는 브라우저를 연 뒤 반환하고 상태를 조회한다. 취소·시간 초과·앱 종료·연결
삭제 시 callback과 진행 중 요청을 종료한다. 갱신은 연결별 한 번만 실행하며 도구 호출이
로그인 창을 열거나 쓰기 작업을 자동 재시도하지 않는다. 새 서비스는 도구를 기본 차단하고
사용자가 확인 후 허용한다. 터미널에서 서비스와 MCP를 함께 선택한다.

검증: 기존 데이터 마이그레이션·로그인 격리 보존, OAuth HTTP fixture의 실제 PKCE 교환·
잘못된 state·재사용·취소·갱신·재시작·비밀정보 비노출, gateway 도구 호출과 권한 차단,
실제 Electron UI의 웹 앱/커넥터/MCP 분리와 설정 복원을 확인한다. 실제 서비스 계정 승인이
없으면 실계정 API 검증은 미완료로 구분한다. Antigravity OpenAI 경로의 기존 도구 호출
제약은 유지된다.

순차 설계 검토: 기존 gateway와 암호화 저장소를 재사용한다. callback은 사용자 입력을
반사하지 않고, 취소 이후 비동기 저장이 인증을 복원하지 않도록 수명 검사를 저장 큐 안에서도
실행한다. 웹 세션을 서비스 인증으로 취급하지 않는다.
